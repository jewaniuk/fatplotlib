# fig

git mode: main

python library for academic figures that mix schematics, diagrams and data plots on one canvas, with typst for text and math, svg output, a hot-reload preview, light and dark themes, and auto-placed panel labels.

- the design plan lives in `planning/PLAN.md` (local only, gitignored). read the sections a task needs rather than the whole file
- `uv` manages the environment: `uv run`, `uv add`
